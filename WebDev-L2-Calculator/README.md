# 🧮 Modern Calculator

A modern and responsive calculator web application built using HTML, CSS, and JavaScript. It performs basic arithmetic operations with a clean and user-friendly interface.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- % Percentage
- 🧹 Clear (C)
- ⌫ Backspace
- ⌨️ Keyboard Support
- 📱 Responsive Design
- 🎨 Modern Glassmorphism UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
