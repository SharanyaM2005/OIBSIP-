# 🔐 Login Authentication

A modern and responsive Login Authentication web application built using HTML, CSS, and JavaScript. The project provides a clean user interface for login and registration with basic form validation.

## ✨ Features

- 🔐 Login form
- 📝 User registration form
- 👤 Username/Email input
- 🔑 Password input
- 👁️ Show/Hide password
- ✅ Form validation
- 📱 Responsive design
- 🎨 Modern and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
