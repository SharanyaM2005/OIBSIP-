# Modern Calculator

## 📌 Project Overview
A modern calculator built using HTML, CSS, and JavaScript. It performs basic arithmetic operations with a clean, responsive, and user-friendly interface.

## ✨ Features
- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Clear (C)
- Backspace (⌫)
- Keyboard Support
- Responsive Design
- Modern Glassmorphism UI

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
